# Artwork by morpheus284

The launcher's start screen look is original artwork by [morpheus284](https://github.com/morpheus284), made
for this project ([Core of Light #78](https://github.com/tsapZ/SkylandersCoreOfLight/issues/78)) and licensed
under [Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/):

- `card_base.png`, `card_light.png`: the card frames (the chosen card's lit)
- `option_bar.png`: the bottom options bar
- `background.jpg`: the start screen's background (made from scratch, without game screenshots or official
  artwork as a reference, as he wrote on #78)
- `icon.png`: the launcher's icon (`src/coreoflight_morpheus284.ico` is made from it)

Scaled for the launcher (frames and bar to a quarter, the background as JPEG, the icon padded square into
seven sizes); nothing else changed. They are built into `coreoflight.exe`.
