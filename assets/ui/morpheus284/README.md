# Frames by morpheus284

The card frames (`card_base.png`, `card_light.png` for the chosen card) and the bottom options bar
(`option_bar.png`) of the launcher's start screen are original artwork by
[morpheus284](https://github.com/morpheus284), made for this project
([Core of Light #78](https://github.com/tsapZ/SkylandersCoreOfLight/issues/78)) and licensed under
[Creative Commons Attribution 4.0 International (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/).

Scaled to a quarter of their size for the launcher (they are built into `coreoflight.exe`); nothing
else changed.
